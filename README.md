# Personal Expense Tracker

## Project Overview
The Personal Expense Tracker is a Python-based application designed to help users record, manage, search, and analyze their daily expenses.

## Features
- Add new expenses
- View all expenses
- Search by category
- Calculate total expenses
- Monthly expense summaries
- Delete expenses
- Exit

## Technologies Used
- Python
- Google Colab
- CSV File Handling
- GitHub

## How to Run
1. Download the Python source code.
2. Open Google Colab or any Python environment.
3. Upload and execute the Python file.
4. Follow the menu instructions to manage expenses.

## Data Storage
Expense records are stored in a CSV file named `expenses.csv`.
